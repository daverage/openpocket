# Legacy synth tools

These benches cover the Duo tracker, Pulse/Saw/Arcade/FM Poly, String Duo, acoustic voices, ensembles, and mono synths.
The C benches require engine headers from the `synth` branch. Use commit `06358805` to reproduce the original builds.
For the removal history, see [Synth2 dependencies](../../docs/research/synth2/SYNTH2-DEPENDENCIES.md).
