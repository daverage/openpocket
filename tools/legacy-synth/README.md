# Legacy synth tools (not built)

Benches and research scripts of the SYNTH voices Synth2 retired (Duo tracker, Pulse/Saw/Arcade/FM Poly, String Duo, acoustic voices, ensembles, mono synths).
They include engine headers that no longer exist in this tree, so they do not compile here. They build on the `synth` branch
(source `06358805`), which is kept as the reference. Moved, not edited. See docs/SYNTH2-DEPENDENCIES.md.
