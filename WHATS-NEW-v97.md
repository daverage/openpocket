# OpenPocket v97 · build 997

- Save two or three scenes per patch. Each scene recalls effect states, parameters, Valve settings and patch level. Delay and reverb tails carry over when TAILS is on.
- On the pedal, open Scenes from PLAY with HOME, FX, then PUSH. Set Scene Count to 2 for A/B switching, or 3 for A/B/C. Scene C stays saved when hidden. Hold CAB to cycle footswitch modes on a scene-enabled patch.
- The PLAY screen shows the active scene and patch level. The web editor puts scene selection above the signal chain and groups patch and footswitch controls beside the effect editor.
- Strings Octave and Choir Octave use the pad's existing octave voices. Octave Mix adjusts their level.
- Poly Shifter uses the Poly Octave HQ voices at exact octaves. Older patches using Drop Tune open with the pitch block bypassed.
