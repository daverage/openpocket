# tests/archive

Finished research harnesses and prototypes. Nothing here is run by `make test` and nothing in `engine/`, `firmware/` or `docs/*.html|js` depends on it. Scripts were moved one level down; they resolve the repository root from their own location, so they still run from here.

| folder | what | write-up |
|---|---|---|
| `fasttrack/` | FastTrack host harness for the note tracker (branch `synth3-fasttrack`) | `docs/archive/fasttrack/` |
| `polytrack/` | polyphonic tracking experiments (`cache/`, `cache_final/` are git-ignored data) | `docs/archive/polytrack/` |
| `enhance/` | ENHANCE offline prototype and simulator measurements | `docs/archive/enhance/` |
