# Prompt for the next agent

I'm working on OpenPocket for Donner Pocket X and M-VAVE BlackBox. Build a host listening prototype for realistic **cello-range bowed strings** and **solo trumpet** driven by a guitar. Read `docs/research/REALISTIC-INSTRUMENT-SYNTHESIS.md` for the research, sources, hardware budget, and evaluation plan. Use `docs/research/SYNTH-VOICING-RESEARCH.md` to understand the current BRASS and STRINGS voicings.

1. Pick a few documented, redistributable recordings per voice. Start with VSCO 2 Community Edition's trumpet and cello section, or a suitably licensed dry solo cello recording if available. Keep the authentic attack, make a crossfaded sustain loop, and add a controlled release. Record the source, license, tuning, and loop points for each asset.
2. Render both instruments with known pitch, gate, and expression events first. Include quiet and accented notes, a held swell, a legato bend, and fast repicks. Provide level-matched WAV comparisons against the current BRASS and STRINGS rendered from the same clean DI phrases. Use the fixture to judge instrument sound separately from tracking.
3. Drive the strongest voice with OpenPocket's existing single-note HQ tracker. Use pick strength for articulation, the smoothed envelope for bow or breath intensity, and continuous pitch for bends. Measure lock time, wet onset, wrong notes, and missed repicks on the same phrases. Evaluate double stops separately after the solo path works.
4. Deliver a runnable host prototype, the comparison WAVs, and a short recommendation on which voice to port. Include estimated flash and RAM use and distinguish host timings from measured pedal timings. Keep this first pass in the host so we can choose the sound by listening before integrating it into firmware.
